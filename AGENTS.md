# Freedom project instructions

After implementing a visual or functional change:

1. Work on a separate branch.
2. Run the relevant checks.
3. Show me the result, including a visual preview for design work.
4. Commit the completed changes, push the branch and open a pull request.
5. Present the standard clickable review or merge link so I can approve it by tapping.
6. Never merge the pull request, deploy or make the change live until I use the approval or merge control.
7. Do not ask me to type "approved" when a clickable review or merge control is available.

Apply this workflow to future Cursor and Codex work in the Freedom repository.
